Memory

Memory, notes and reminders stay on this phone. Clearing the conversation keeps what Jarvis remembers about you.

AI provider

Pick which AI answers you. A green dot means you've added a key for it. Gemini, Groq and Mistral have free tiers; Groq is the fastest. Leave the model blank and Jarvis picks a quick one.

API keys

Add as many as you like. Keys are stored only on this phone and sent only to that provider. Tap “Get key” to open the provider's key page, copy the key, and paste it here.

Connection

Keys typed here are stored only on this phone. To keep them off the phone, put them in the Jarvis server's .env file and choose “Always via Jarvis server”.
